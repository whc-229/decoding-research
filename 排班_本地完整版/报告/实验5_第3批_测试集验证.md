## 读法与异常
- **原来的 r47、r35 是三次里最好的一次**：重复运行测试集 HV 低 0.01～0.09。只看各一次会高估 LLM 规则；按各次平均，
  ES16、GP 与 LLM-score 同档（Holm 校正后两两不显著），显著好于 EoH；ES16 在设计运行之间最稳（极差 0.001，LLM-full 0.093、LLM-score 0.069）。
- **"理论诊断反馈（full）优于只给分数（score）"不成立**：三次平均 full 0.687、score 0.709（方向相反；原始 p = 0.018，Holm 校正后 0.14，不显著）；
  加上 r35 > r47 的旧结论在服务器上也已不成立，这一消融目前只能说"没有看到 full 反馈的好处"。
- 代理分与测试集高度一致：换 3 批新基因后的代理分与测试集 HV，28 条规则 Spearman ρ = 0.91（p=1e-11），
  只看 9 条 LLM/EoH 规则 ρ = 0.92；但测试集把差距放大——新 LLM 规则的新基因代理分 0.813～0.823（与 GP、IL16 同档），测试集 0.644～0.724。
  换基因的乐观偏差很小（相对默认 ≤ 0.012），所以落差主要来自换实例，而不是对 67 个基因过拟合。
- 不可行：5 条新 LLM 规则（full_s2、full_s3、score_s2、score_s3、EoH run1）在测试实例 H13_720h 上 5 次中 4～5 次找不到可行解（按 HV = 0 计）；
  IL32-16(s2) 在 M22_1080h、M26_1080h 上共 3 次。训练实例上都没有出现。
- 设计成本（LLM）：rulegen 每次 53～58 次调用；EoH 每次 64～111 次调用（抽取失败与重复会重问），输出 token 51～57 万。
