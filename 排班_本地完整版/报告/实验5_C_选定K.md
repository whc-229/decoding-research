# 实验 5 任务 C：在训练实例上选定最终方法的偏离密度 K（2026-10-22）

**K 由训练实例按事先固定的规则选出**：15 个训练实例上跑 NSGA-II（465 次评价，种子 5000+次号），每个实例内全部臂统一归一化 HV，
对 8 条规则（ES16 s0～s2、GP run1～5）× 5 次取平均，平均 HV 最高的 K 为最终 K；ES16、GP 两族分别报告，不一致时以 8 条合并为准。
判定代码（neural/c2_choose.py）在跑 C1 之前写好并用假数据测试过，测试集不参与。

**候选 K ∈ {0.25, 0.5}**：K0.5 是现有编码能表示的最大偏离密度。K0.75 的偏离槽会被截到与 K0.5 相同（基因前半段只放得下 K0.5 的槽），
默认类型基因还会落进工具基因区，跑出来不代表更高密度；2026-10-21 决定不比 K0.75。

## 结论
1. **选出 K = 0.5**，两族一致：合并 0.7080 对 0.6309，ES16 0.7326 对 0.6493，GP 0.6933 对 0.6199。
   K0.5 对 K0.25 +0.077，15 个训练实例中 14 个更好（配对 Wilcoxon p = 4e-4）。
2. 因此任务 B 中"固定 K0.5 + 好规则"的测试集结果可以直接作为最终方法的成绩引用（K 不再是看测试集挑的）：
   NSGA-II-465 下 K0.5 + ES16 0.781、K0.5 + GP 0.774，对 dec5 +0.20（Holm p < 1e-6），E 组追平 dec5（+0.006、+0.019，不显著），
   M 组 +0.35（16/16）。NSGA-II-2000 下 K0.5 + ES16 0.782，对 dec5 +0.218（Holm p = 1e-7），E 组 +0.051（不显著）。
3. **训练实例上 E 组仍略低于 dec5**：E 组 K0.5 0.605、dec5 0.634（5 个实例）；K0.25 只有 0.454。测试集 E 组（12 个实例）K0.5 追平了 dec5。
   所以"E 组追平"只能写成追平，不能写成超过。
4. **C3（理论对照）**：K0.25 时规则到最近 dec5 好解的距离 dev / 槽数，E 组中位 1.01（3/5 个实例 > 1），H 组 0.47、M 组 0.16（都没有 > 1）；
   K0.5 时所有实例都 < 1（最大 0.66）。即 K0.25 在 E 组的部分实例上槽数不够覆盖到最近好解的距离，K0.5 够了。
   但 dev / 槽数与"K0.5 对 K0.25 增益"的秩相关不显著（Spearman ρ = 0.34，p = 0.22，15 个实例）：H、M 组 dev 远小于槽数，
   K0.5 仍有 +0.03～+0.10 的增益（H17、M23 的 dev / 槽数 ≤ 0.16，增益 +0.09～+0.10），说明 K0.5 的好处不只是"补足到最近好解的距离"。
