# R0：排班偏离率扫描——κ = 1.0 下提高生效概率 q（2026-10-23）

## 结论
1. **最终方法不变：保留 κ = 1.0、q = 0.4。** 按事先写死的规则，κ = 1.0 一线（q = 0.4 / 0.6 / 0.8）训练平均 HV 最高的就是 q = 0.4（0.6056），所以不改、不跑测试集。
2. **q·κ 超过 0.4 后 HV 往下走，但不显著，不能说出现了下降段。** 合并 8 条规则：q·κ = 0.4 时 0.6056 → 0.6 时 0.5903 → 0.8 时 0.5778；
   q0.8 对 q0.4 −0.028，5/10 个实例好/差，配对 Wilcoxon p = 0.15。按事先定义（q0.8 低于该线最高点且 p < 0.05），全部与 E/H/M 都"否"。
   幅度也比 FJSP 小：FJSP 465 次时 q = 0.4 一线从峰值 0.793 降到 0.725（f = 1.0），q = 0.6 降到 0.635（报告/T3_分析.md）。
3. **起作用的更像是 q·κ，而不是 κ 本身。** κ = 0.5、q = 0.8 与 κ = 1.0、q = 0.4（q·κ 都是 0.4）只差 −0.007（6/8，p = 0.47）；
   而同为 κ = 0.5，把 q 从 0.4 提到 0.8 提高 +0.047（13/2，p = 0.008）。
4. **前沿解里生效的槽占比 ≈ q**（0.387 / 0.590 / 0.791，κ = 0.5、q = 0.8 时 0.795），与 FJSP 的 P1"最好解的偏离数 / 槽数 ≈ q"一致；
   实际用到的偏离（落在已排班次内、去掉同班重复）占槽数 0.30 / 0.41 / 0.50，占班次数 0.32 / 0.44 / 0.54。q·κ 相同的两组，偏离数 / 班次数也几乎相同（0.330 与 0.324）。

## 设定
- 15 个训练实例，NSGA-II 465 次，种子 5000 + 次号，8 条规则（ES16 s0～s2、GP run1～5）× 5 次；扩展布局（ruledec_ext），偏离槽 a ≥ dev_on 生效，q = 1 − dev_on。
- 新臂（out/train_q.csv，1800 次运行）：κ = 1.0、q ∈ {0.6, 0.8}；κ = 0.5、q = 0.8。q = 0.4 的 X0.5、X0.75、X1.0 用 T10 的 out/train_Kext.csv（同一台机器）。
- 每个实例内 6 × 8 个臂统一归一化 HV；方法层面 = 实例内 8 条规则 × 5 次的平均；实例层面配对 Wilcoxon（15 个实例）。
- 判定规则（跑之前写死，neural/r0_choose.py，假数据三种情形测试通过）：κ = 1.0 的 q ∈ {0.4, 0.6, 0.8} 中合并训练平均 HV 最高者；
  不是 q = 0.4 且对 q = 0.4 配对 Wilcoxon p < 0.05 才改，否则保留 q = 0.4。改了才补跑测试集。
