# T11：偏离偏置与最优 K——在规则距离模型里的检验（2026-10-22）

对应 `报告/待检验_偏离偏置与最优K.md` 的检验 A、B。另加一个文档没要求的对照 D（多余偏离的代价 λ < 1），单独标明。

## 结论（先看这里）
1. **A（偏离值有偏）不能解释现象。** 偏置只提高"槽落到目标位置后取对值"的概率 p_hit；在 d 大时把最优 K 往上推（465 次、d = 40：K 30 → 50），
   但 d = 2、5 时最优 K 仍是 2～8，K 25 → 50 在所有 (β, γ) 下都变差（465 次 +4.7～+5.7，2000 次 +2.8～+4.3 个汉明距离，标准误约 0.3～0.5）。
   原因：多余的生效槽落在非目标位置上，无论取什么值都是 1 个错误，偏置改变不了这一点。平均场推广给出同样的结论（p_hit 0.33 → 0.85，465 次、d = 2 的最优 K 只从 5 变到 7）。
2. **B（多个目标）能解释"最优 K 远大于到最近好解的距离"，但在 465 次预算下不能复现"K 加倍仍有增益"。**
   - 目标离规则的距离分散时，最优 K 跟着 **平均 d** 走，而不是最近的 d：含近目标（d = 2）且有远目标的集合，最优 K / 最小 d 在 465 次为 4～7.5，2000 次为 5～15；最优 K / 平均 d 在 465 次约 0.45～1.7，2000 次约 1～1.7（与单目标时 K/d 的水平相当）。
   - 但在 465 次预算下，所有多目标集合中 K 25 → 50 仍然变差（+2.6～+5.6；单目标 d = 40 也变差 +1.75）；2000 次时多目标集合的差距缩小到 +0.65～+3.7，加倍更好的只有单目标 d = 40（−2.90±0.61；d = 20 为 −0.85±0.66，不显著）。
3. **已有数据支持 B 的前提**（无需新运行，来自 `neural/out/c3_dev.json`）：H17、M14、M17、M23 到"最近"好解的 dev 只有 0.25～4.4，但到第 1 层好解的 **中位** dev 为 21～35；
   按中位 dev 算，15 个训练实例在 K0.25 下的 dev / 槽数全部在 0.88～1.82，即 K0.25 处处不够覆盖前沿的中段。
   但这个比值与"K0.5 对 K0.25 增益"的秩相关同样不显著（Spearman ρ = −0.17，p = 0.54；原来按最近好解算的是 ρ = 0.34，p = 0.22，已复核）。
   所以 B 能说明"为什么 H、M 组的 K0.5 不该被判为多余"，但说明不了增益在实例之间的大小差异。
4. **额外对照 D：多余偏离的代价越小，最优 K 越大，λ = 0.1 时 d = 5 的 K 加倍已不再变差**（465 次 −0.12±0.18，2000 次 −0.42±0.19）。
   即"多余的槽在排班里不是满额噪声"（偏到次优机器人常常几乎不影响目标，另有槽落在 N 之外不起作用，M 组 N/nmax ≈ 0.67～0.96）在模型里能产生现象；但这一点没有在排班里测过，只是候选。
5. **按检验 C 的写法**：A 不能复现；B 只能部分复现（解释了 K ≫ 最近 d，没复现 465 次时加倍的增益）。张力至少部分来自"dev 只量到最近好解、低估了 HV 需要覆盖的距离"（B，有数据支持），
   剩下的部分在本模型里只能由"多余偏离近乎无代价"（D）产生。建议写进实验 6a 的扩展结论的只有："**多个目标解时最优偏离数随目标间的离散而变大，跟随平均距离而不是最近距离**"；
   "偏离值本身带偏置使最优偏离数变大"在 d 小的区间不成立，不建议写。

## 设定
- 模型：`theory/model.py` 的规则距离模型，N = 100，m = 4，q = 0.4，GA 算子与 ga.py 相同（种群 30，SBX η = 20，多项式变异每位 1/n），预算 465 / 2000（同一次运行的两个检查点），每格 20 个种子。
  K ∈ {2, 3, 5, 8, 10, 15, 20, 25, 30, 40, 50, 60, 80}。"最优 K" = 平均值最小者；"近优范围" = 平均值不超过 最优值 + 最优格标准误 的 K。"加倍" = f(K50) − f(K25)，同种子配对（目标相同），负数表示加倍更好。
  K 25 / 50 对应排班里 N ≈ 100 的实例 K0.25 ≈ 27、K0.5 ≈ 54 槽。
- A：生效偏离以 β 取值 1（规则的次优值），否则在 2..m−1 均匀；目标的 d 个偏离位置以 γ 取值 1。(β, γ) ∈ {1/3（均匀，即原模型）} ∪ {0.5, 0.85} × {0, 0.5, 1}，d ∈ {2, 5, 10, 20, 40}。单目标 GA，f = 汉明距离。
- B：t = 1～3 个目标，偏离位置独立（indep）或嵌套（nest：近目标的偏离是远目标的子集，取值相同）；偏离取值均匀。NSGA-II，目标向量 = 到各目标的距离；
  指标 = 各目标在全部已评价解中的最小距离的平均（对应 HV 要覆盖整条前沿）。
- D（额外）：f = 目标位置错误数 + λ·非目标位置偏离数，λ ∈ {1, 0.5, 0.25, 0.1}，d ∈ {2, 5, 10, 20}。
- 平均场：`meanfield.predict` 中"取对值的概率 1/(m−1)"换成 p_hit = γβ + (1−γ)(1−β)/(m−2)，α、β_mf 沿用 sweep.json 的拟合（0.05、1.5），未重新拟合。
- 自检（`python bias_multi.py test`）：β = 1/(m−1) 时新解码与 model.decode_sp 逐解相同（m = 3/4/5 × 4 种 K × 2000 个基因，0 不一致）；
  多目标非支配排序与拥挤度与 ga.py 相同（300 组，0 不一致）；p_hit 与经验命中率相符（0.85/0.866、0.075/0.067、0.375/0.356）。
- 运行：conda 环境 ana，2 个进程，A 9100 次（约 18 分钟）、B 4160 次（9 分钟）、D 4160 次（9 分钟），无异常。

## 注意
- 模型的绝对尺度（汉明距离、q = 0.4、m = 4）没有对排班标定；"465 次时 K 加倍变差"在模型里很稳，但排班里的 465 次未必对应模型里的 465 次。
- B 与 D 的组合（多目标 + 多余偏离近乎无代价）没有跑；若需要，改 bias_multi.py 的 job_B 加 λ 即可，约 10 分钟。
- D 的前提（排班里偏到次优动作的代价小）没有在排班上量过；可以用现有好解做：随机把 k 个班次改成规则次优动作，看两个目标变多少。
