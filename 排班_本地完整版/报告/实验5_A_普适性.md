统计口径同实验 5：每种优化器 / 预算各自在实例内统一归一化 HV（13 个臂）；方法层面先对设计运行 × 5 次取平均，再做实例层面配对 Wilcoxon；

## A1：MOEA/D（465 次评价）
实现：neural/moea_any.py `--algo moead`，照 bench/moea_fjsp2.py 的 run_moead（Tchebycheff、30 个权向量、邻域 6、SBX + 多项式变异、最多替换 2 个邻居）。
与 FJSP 版的唯一不同：排班有不可行解，理想点 / 最差点只用可行解计算，不可行解的 Tchebycheff 值记为 +∞。自检：2 个实例上正常运行，结果量级与 NSGA-II 相近。
输出 neural/out/val_moead.csv，表 neural/out/val_A_moead.md（对照 neural/out/val_A_nsga465.md）。

### A2 读法
- **主要结论在大预算下保持**：好规则（K0.25）对 dec5 +0.13～+0.16、对默认 +0.11～+0.15，全部显著；默认规则对 dec5 仍不显著。
- **K0.25 三种方法的排序在大预算下拉开了一点**：ES16 0.726 > GP 0.708（刚好显著）> LLM-score 0.694（与 GP 不显著）。
- **E 组**：预算加大后 K0.25 规则方法与 dec5 的差缩小到不显著（−0.035～−0.063）；ES16@K0.5 在两种预算下都追平 dec5（+0.012、+0.051，不显著）。
- **"大预算下最优偏离数变大"的预言没有得到支持**：K0.5 对 K0.25 的增益在 465 次与 2000 次几乎相同（+0.056、+0.055）；E 组反而缩小（+0.112 → +0.086），
  H 组略增（+0.056 → +0.066）。可能的解释：现有编码最多只能表示 K0.5，若 465 次时最优已在 K0.5 附近或更高，2000 次也测不出"变大"。

## A3 小结：三档结论是否保持
| 结论 | NSGA-II 465（实验 5 主表） | MOEA/D 465 | NSGA-II 2000 |
|---|---|---|---|
| 好规则对 dec5、对默认规则显著更好 | 是 | 是 | 是 |
| 默认规则对 dec5 不显著 | 是 | 是 | 是 |
| 第一档 ES16、GP、LLM-score 两两不显著 | 是 | **否**：LLM-score 显著低于 GP、ES16 | **部分**：ES16 > GP（Holm 0.049），LLM-score 与 GP 不显著 |
| ES16 设计运行间最稳 | 是（极差 0.001） | 是（0.015，LLM-score 0.083） | 是（0.016，LLM-score 0.066） |
| E 组 K0.25 规则方法不如 dec5 | 全部显著 | 全部显著 | 差距缩小，均不显著 |
| K0.5 好于 K0.25（ES16） | +0.051（任务 B） | +0.047（任务 C4，Holm p = 1e-6；GP +0.030） | +0.055 |

稳健的说法：**按代理分直接优化出的规则（ES16、GP）在两种优化器、两种预算下都显著优于 dec5 和默认规则；ES16 在设计运行之间最稳；
LLM 规则在 NSGA-II-465 下与之同档，但换优化器或加大预算后有落后的迹象。**
