# FJSP 基准 v2（插空解码 + 大预算 + 与已知最好解对照）

改动：
1. 插空：所有编码都把工序放进机器上最早能容纳它的空闲段（主动调度）。双段随机键因此变强，对比更公平。
2. 大预算：最多记录到 20000 次评价（465 / 2000 / 5000 / 10000 / 20000 各记一次）。
3. 间隙相对已知最好解（BKS），另可报相对下界。
4. 每次运行还记录"当前最好解相对规则偏离了几步"（用于检验解析模型）。
不插空时与 v1 逐解相同（check_v2.py，360 条全部一致）。

## 运行（在 实验0_表示分析\bench\ 下，一次只跑一条，不要开两个窗口写同一个文件）
```
python moea_fjsp2.py pd,rk,sp0.1,sp0.25,sp0.5 5 auto v2_main.csv main 5000
python moea_fjsp2.py rk,sp0.1,sp0.25,sp0.5 5 auto v2_big.csv big 20000
```
- 第一条：除 Behnke 外的 276 个实例，5000 次评价，约 2～3 小时。
- 第二条：Brandimarte、Dauzère、Barnes、Kacem、Fattahi 共 78 个实例，20000 次评价，约 2～3 小时。
- 可选（最慢，最多 500 道工序）：`python moea_fjsp2.py rk,sp0.1,sp0.25,sp0.5 5 auto v2_behnke.csv behnke 5000`
- auto 最多 8 个进程；另一个对话的实验也在跑时改成 4。断了重跑同一条命令会接着跑。
