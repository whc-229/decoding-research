# 公开基准：柔性作业车间（FJSP）

把"规则 + 稀疏偏离"框架搬到 FJSP 上，检验偏置–自由度的结论能否推广。
- 实例：`fjsp-instances/`（SchedulingLab/fjsp-instances，336 个：Brandimarte 15、Hurink 198、Dauzère 18、Barnes 21、Kacem 4、Fattahi 20、Behnke 60），带最优值或上下界。
- 规则：最早完工优先（ECT），并列时剩余工作量大的工件优先。
- 编码：pd（逐步基因）、rk（经典双段随机键，文献基线）、sp0.1 / sp0.25 / sp0.5（稀疏偏离，槽数 = 比例 × 工序数）。
- NSGA-II 种群 30，目标 (makespan, 总负荷)，每次运行在 465 / 2000 / 5000 次评价处各记录一次前沿。

## 运行（在 实验0_表示分析\bench\ 下）
```
python moea_fjsp.py pd,rk,sp0.1,sp0.25,sp0.5 5 auto runs_hdbb.csv hurink
python moea_fjsp.py pd,rk,sp0.1,sp0.25,sp0.5 5 auto runs_hdbb.csv dauzere
python moea_fjsp.py pd,rk,sp0.1,sp0.25,sp0.5 5 auto runs_hdbb.csv barnes
python moea_fjsp.py pd,rk,sp0.1,sp0.25,sp0.5 5 auto runs_hdbb.csv behnke
```
四条按顺序跑（写同一个文件，会自动跳过已完成的）。Brandimarte、Kacem、Fattahi 我在云端跑。
断了重跑同一条命令即可继续。跑完告诉我。
