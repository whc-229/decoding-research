# neural/ 在服务器上运行

## 一次性：把当前文件夹搬上去
服务器上的旧文件先改名保留（不要和新文件混在一起）：
    mv ~/解码研究/排班_本地完整版 ~/解码研究/排班_本地完整版_旧
在 Windows PowerShell 里：
    scp -r "D:\whc\论文\解码研究\排班_本地完整版" hk@服务器IP:~/解码研究/
需要 numpy、scipy（conda base 一般都有）。不需要 GPU、PyTorch。

## 每一批
1. 我改完代码后，只同步 neural/ 文件夹：
       scp -r "D:\whc\论文\解码研究\排班_本地完整版\实验0_表示分析\neural" hk@服务器IP:~/解码研究/排班_本地完整版/实验0_表示分析/
2. 服务器上：
       tmux new -s nn
       cd ~/解码研究/排班_本地完整版/实验0_表示分析/neural
       bash run_batch1.sh auto
   按 Ctrl-b 再按 d 离开，tmux attach -t nn 回来看。断了重跑同一条命令，已完成的会跳过。
3. 跑完把结果拷回 Windows（在 PowerShell 里）：
       scp "hk@服务器IP:~/解码研究/排班_本地完整版/实验0_表示分析/neural/out/*.*" "D:\whc\论文\解码研究\排班_本地完整版\实验0_表示分析\neural\out\"

## 说明
- 同一台机器上重复运行结果完全相同；但不同机器 / numpy 版本之间不逐位相同（NSGA-II 对浮点末位敏感），
  所以对比所用的全部臂（含 dec5、默认规则、r47、r35）都在服务器上重跑，Windows 上的 val_full.csv 只作复现性对照。
- 所有脚本默认 auto = CPU 核数 − 1 个进程。
