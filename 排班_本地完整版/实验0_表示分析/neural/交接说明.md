# 实验 5 交接说明（2026-10-19，之前在 claude.ai 对话里进行，现在转到服务器上用 Claude Code 继续）

## 1. 目标
实现并评价"用神经网络训练一个解码器"（老师提出），以及同属"规则从哪里来"的对比方法，形成论文中
"手写规则 / 遗传规划规则 / 神经网络规则 / LLM 规则"的对比实验章节，最后写成报告 `neural/实验5_结论.md`
（用户会把它放进 claude.ai 项目文档 claude/实验5_神经网络与规则来源对比_结论.md）。

## 2. 背景（来自项目文档，关键数字）
- 稀疏偏离编码（K = ⌈0.25·班次上界⌉ 个偏离槽 (p, a)，a ≥ 0.6 生效）：不偏离的班次由"默认规则"决定，规则就是搜索偏置。
  规则接口 `rule(ctx) -> 按偏好排序的动作列表`，动作 ("reuse", 机器人视图) 或 ("new", 类型)。第一个 = 不偏离时的动作；
  改派偏离在其余 reuse 中按顺序选。见 rulegen/ruledec.py。
- 实验 2：E 组失败的原因是默认规则离好解远（dev/K 0.70～0.83 的实例显著变差）。
- 实验 4a（LLM 规则，EoH 式进化，deepseek-flash，约 55 次调用，代理分 = 15 个训练实例 × 67 个固定基因解码结果的归一化 HV）：
  测试集 47 个实例 × 5 次（Windows/旧环境）：dec5 0.607，稀疏+默认规则 0.589，稀疏+LLM 规则 r47（full 反馈）0.732、r35（只给总分）0.763。
  full/score 两种反馈各只跑了 1 次，消融结论未定。规则文件：rulegen/out/full/best_rule.py（r47）、rulegen/out/score/best_rule.py（r35）。
- 实验 6（另一条线，不要重复）：偏置–自由度解析模型（小预算最优槽数 ≈ 规则距离 d）与 FJSP 公开基准。
  其中一个发现与本任务相关：LLM 规则的收益来自"让规则附近出现别的好解"，规则距离应按到最近好解计。

## 7. 注意事项（以前踩过的坑）
- 稀疏偏离运行里好解的大部分班次就是规则自己的选择，所以模仿学习的标签必须来自排班本身（重放 sim.seq），老师用 dec5 的解；否则只会学回老师规则。
- 双目标：同一状态下不同非支配解可能选不同动作；目前用加权交叉熵。可选变体：偏好条件化（1 个基因给偏好 λ）。
- 偏离会把状态带离老师轨迹（分布偏移），ES 微调用来补救。
- 公平性：每种方法报告设计成本；每种方法多次独立设计运行（GP 5、rulegen 每种反馈 3、EoH 3），测试集同时报"各次平均"和"最好一次"。
- 用户的 Windows 和 Linux 虚拟机之后不再跑实验；需要用户本地读的结果，用户会从服务器下载。
