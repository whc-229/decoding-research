# 任务 B：按实例选编码 + 好规则（测试集）

47 个测试实例；HV 在每个实例内用 val_server.csv 的全部 38 个臂统一归一化。选档：每档 100 个固定随机基因的最好解（先资源数后均衡度），平局按 dec5、K0.25、K0.5。方法的值 = 选中档臂的 5 次 MOEA 平均 HV，再对同一族的规则（ES16 3 条、GP 5 条）取平均。p = 实例层面配对 Wilcoxon；Holm 校正在每个分组内对下表的全部比较（每族 4 个对照 × 2 族 = 8 个）一起做。"事后最好档"按 MOEA 结果挑，只作上限，不参与检验。好/差实例数 = 实例平均 HV 差为正 / 负的实例数（不是逐实例检验）。
